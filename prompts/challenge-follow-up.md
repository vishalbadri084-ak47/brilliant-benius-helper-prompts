# Challenge email / WhatsApp sequence

Copy the prompt below and replace the [BRACKETS]. Read the README checks before using it.

```text
Write a 5-message follow-up sequence for people who joined the free 7-Day AI Marketing Challenge from Brilliant Benius.
Audience: [FREELANCER TYPE, e.g. designer, video editor, writer].
Message 1: welcome, how the challenge works (one lesson unlocks each morning, come back each day).

Message 5: invite to share what they got done. No hard sell.
Format: each message under 80 words, plain text, WhatsApp-friendly, one clear action per message.
```
