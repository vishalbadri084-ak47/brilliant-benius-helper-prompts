# SEO check for a page

Copy the prompt below and replace the [BRACKETS]. Read the README checks before using it.

```text
Here is the text of a page from Brilliant Benius: [PASTE TEXT]. Target search phrase: [PHRASE, e.g. "how freelancers in India get clients"]. Check it and tell me, in simple points:
1. Is the title under 60 characters and does it include the phrase?
2. Does the first paragraph answer the search quickly?
3. Which 3 related phrases should be added naturally?
4. Is anything vague, repeated or too long?
5. Write a better title and a 150-character description.
Give the top 5 fixes ranked by effort (small first). Do not stuff keywords.
```
